## 🚀 About me

Over four years in Azure and multi-cloud environments. Today I'm a **DevOps Engineer at [Enbros Technologies](https://enbros.co.uk)**, building CI/CD pipelines, Terraform and Bicep infrastructure and Kubernetes platforms, and owning mobile release pipelines (Expo/EAS, App Store Connect, Google Play).

Before that I worked as a cloud support engineer on Azure, solving complex APIM, ARM/Bicep and Cloud Services issues for enterprise customers, and ran DevOps for fintech workloads on AWS. I'm a business-school graduate who fell for technology, and I believe in *Security-as-Code*: compliance and monitoring belong early in the SDLC, not after release.

## 📈 What I've shipped

- ☁️ **Get Set Hire**: a logistics and equipment-hire platform, fully on Azure. Terraform for every environment, Azure DevOps release pipelines with zero-downtime deploys, and an AI quote-parsing service on Azure OpenAI.
- 🏦 **Waya (fintech)**: GitHub Actions to Amazon ECR and ECS/EKS deployments under PCI DSS/CBN controls, with Prometheus and Grafana monitoring.
- 🏠 **Property Ladder**: zero-trust, keyless (OIDC/Workload Identity) CI/CD to Google Cloud Run with Trivy scanning and a private VPC.
